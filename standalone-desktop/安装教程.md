# 肆喵 · 安装教程（傻瓜版）

> 目标：**双击一个文件，桌面上就多出一只肆喵。**
> 不需要 DSH、不需要 Node、不需要命令行知识、不需要管理员权限。

---

## 一、Windows：三步（其实只要第 2 步动手）

### 第 1 步：下载

打开 <https://github.com/sijin14514-sys/simiao-dsh-pet/releases/latest>
下载 **`simiao-standalone-desktop-*.zip`**（约 6 MB）。

### 第 2 步：解压后双击

用资源管理器右键 zip → **全部解压缩**（⚠️ 不要直接在 zip 里双击运行），

确认解压出来的文件夹里有这些东西：

```text
simiao-standalone-desktop/
├─ 一键安装-肆喵.cmd        ← 双击这个
├─ 安装肆喵.ps1
├─ characters/             ← 角色素材（20 段动画）
├─ README.md
└─ 安装教程.md             ← 你正在看的内容
```

**双击「一键安装-肆喵.cmd」**，然后等它自己跑完。

它会依次自动完成：

| 步骤 | 它在做什么 | 你要做的 |
|---|---|---|
| ① 检查独立桌宠程序 | 没装就**自动从 GitHub 下载并静默安装**（约 140MB，1~5 分钟） | 等 |
| ② 准备配置 | 自动启动一次程序以生成配置 | 等 |
| ③ 装角色 | 把 20 段动画拷进程序的角色目录 | 等 |
| ④ 切换角色 | 把当前角色改为「肆喵」 | 等 |
| ⑤ 开机自启 | 写一条注册表项（可在菜单里关） | 等 |
| ⑥ 启动 | 启动桌宠 | 看桌面 🐾 |

看到绿色的 **「✅ 安装完成，肆喵已经在桌面上了！」** 就成功了。

### 第 3 步（可选）：调一调

- **拖动**：按住她拖到任意位置
- **点击**：她会做出 5 种随机反应之一（跳跃欢呼 / 被吓一跳 / 生气跺脚 / 鼓掌 / 鞠躬）
- **甩出去**：拖到一定距离松手会飞出去
- **右键**：菜单（换角色 / 播放速度 / 关闭开机自启 / 退出）

## 二、macOS / Linux

同一个 Release 里的 zip，解压后：

```sh
sh install.sh
```

它会把角色装好并切换。**载体程序需要你自己装**（各平台打包形式不同）：

<https://github.com/MerZlin/dsh-pet-indesktop/releases/latest>

装好并**运行过一次**（生成配置）之后，再执行 `install.sh`。

## 三、常见问题

### ❓ 双击 `.cmd` 一闪而过 / 提示"无法加载文件，未数字签名"

Windows 会标记"从网上下载的文件"。解决：

1. 右键下载的 **zip** → 属性 → 最下面勾选 **「解除锁定」** → 确定
2. 重新解压，再双击

（脚本本身用的是 `-ExecutionPolicy Bypass`，无需改系统策略。）

### ❓ 提示"找不到角色素材目录"

你只把 `.ps1` 单独拷出来了。请**把整个解压出来的文件夹一起用**（脚本需要同目录的 `characters/`）。

### ❓ 下载卡住 / 自动下载失败

脚本会提示你手动装：打开 <https://github.com/MerZlin/dsh-pet-indesktop/releases/latest>，
下载文件名以 **`-webm-setup.exe`** 结尾的那个，双击装好，再重新运行安装脚本。

### ❓ 装完了，但桌面上还是那只蓝色的

大概率是 `config.json` 写坏了（**带 BOM 的 UTF-8 会让程序解析失败并静默退回内置角色**——
我们踩过这个坑）。两个办法：

1. 桌宠**右键 → 角色菜单 → 肆喵**手动切换（热加载，立即生效，最省事）
2. 重新运行一次 `一键安装-肆喵.cmd`

### ❓ 桌宠不见了

看**任务栏右下角的托盘区**（可能被折叠在 `^` 里），图标是它。也可能被拖到了屏幕边缘之外。
实在找不到：重新双击 `一键安装-肆喵.cmd`，或直接运行安装目录里的 `dsh-pet-standalone-webm.exe`。

### ❓ 开机自启怎么关

桌宠**右键菜单**里有开关；也可以自己删掉注册表项
`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` 下名为
`dsh-pet-standalone-webm` 的值。

### ❓ 怎么卸载

- **只删宠物**：删掉 `%APPDATA%\dsh-pet-standalone-webm\characters\simiao` 文件夹
- **整个卸载**：Windows「设置 → 应用」里找到 **dsh-pet-standalone (WebM)** 卸载

## 四、原理（给好奇的人）

肆喵的 20 段动画最初是为 [dsh-pet](https://github.com/PC2005-cloud/dsh-pet)（DSH 的桌宠插件）做的。
而 [dsh-pet-indesktop](https://github.com/MerZlin/dsh-pet-indesktop) 是一个把桌宠搬到
Windows / macOS / Linux 上、**不需要 DSH** 的独立程序，并且支持**外部角色目录热加载**。

两个项目用的是**同一套素材规范**：

|  | dsh-pet | dsh-pet-indesktop |
|---|---|---|
| 画布 / 帧率 | 640×360 / 24fps | 640×360 / 24fps |
| 编码 | VP9-alpha webm | VP9-alpha webm |
| 脚底线 | y = 330 | `FEET_Y = 330`（`PAD = 30`） |
| 可点击区 | `HIT_BOX` | `manifest.json` 的 `body_box` |

所以这是**零改代码的搬运**：把 20 段 webm 按它的目录约定放好 + 写一个 `manifest.json` 就能用。

动画的制作方法（AI 图生视频 → 抠绿 → 归一化 → VP9-alpha 编码）与全部脚本，
见本仓库的 [`docs/`](../docs) 与 [`tools/`](../tools)。
