# tools · 脚本索引

这些脚本就是本仓库"方法"的可执行部分。**路径已改成相对仓库根**，clone 下来即可用（需要 Node 18+ / ffmpeg / Python 仅用于可选项）。

> 把 ffmpeg 放到 `tools/ffmpeg/` 下（脚本会自动递归查找 `ffmpeg.exe`）；或用系统 ffmpeg 并自行改脚本里的常量。

## 素材生产（从绿幕视频到桌宠素材）

| 脚本 | 作用 |
|---|---|
| `视频转桌宠.mjs` | **主流程**：抽帧 → HSV 色相抠绿（含左上角水印清除）→ 按站立高度归一化 → 合成 640×360 帧 |
| `抠像.mjs` | 立绘去底：源图自带 alpha 就直接用，纯不透明图才走边缘泛洪兜底 |
| `编码.ps1` | 帧序列 → VP9-alpha webm（`-auto-alt-ref 0`） |
| `批量入库.ps1` | 把 `视频源/*.mp4` 里还没转过的全部转成动画 |
| `检查alpha.mjs` | 检查 PNG 透明像素占比（验证 alpha 是否真的在） |
| `校验.ps1` + `校验.mjs` | ffprobe 元数据 + 抽帧拼总览图（人工验收用） |
| `预览图.ps1` | 把若干段动画拼成一张 GIF 预览 |

## 配置与打包

| 脚本 | 作用 |
|---|---|
| `生成配置.mjs` | **按磁盘上实际存在的动画自动生成 pet pack 配置**（只引用存在的文件，避免 404）；同时同步到 `$DSH_HOME` |
| `打包发布.mjs` | 生成可发布的 `simiao-pet/` 目录（含 install 脚本与说明） |

## 生成自动化（可选，依赖即梦网页）

| 脚本 | 作用 |
|---|---|
| `浏览器.mjs` | 用 Playwright 起一个"专用配置"的 Chrome，并开本地控制口 `127.0.0.1:7799/cmd`（需常驻运行） |
| `浏览器命令.mjs` | 往控制口发一条指令（便于手动调试） |
| `即梦-26-批量生成v2.mjs` | 批量生成：挂首帧（含校验）→ 写提示词 → 提交 → 等新任务 → 取回 → 四道质检 |
| `即梦-40-全部对话收集.mjs` | 遍历所有"对话"，滚动收集 (提示词, 视频) 对 |
| `即梦-41-下载新结果.mjs` | 按提示词匹配 → 下载 → 查重 / 绿幕 / 构图质检 |
| `即梦-42-重做待机.mjs` | 单条重做示例：提示词里加了【发型严格一致】，用于"某段素材有瑕疵"时重做 |

细节与坑见 [`../docs/02-即梦图生视频自动化.md`](../docs/02-即梦图生视频自动化.md)。

## 部署到本机 DSH

| 脚本 | 作用 |
|---|---|
| `启动桌宠.ps1` | 启动器：已在运行就不重复启动；否则隐藏窗口跑 DSH（`--no-open`） |
| `开机自启-安装.ps1` / `开机自启-卸载.ps1` | 让桌宠随 Windows 登录自动出现（注意：桌宠是 DSH 插件，自启的本质是自启 DSH） |

## 环境变量

| 变量 | 用途 |
|---|---|
| `DSH_HOME` | DSH 用户目录（默认 `~/.dsh`）；pet pack 要装到 `$DSH_HOME/dsh-pet/pet/` |
| `DSH_ROOT` | DSH 源码/安装目录（`启动桌宠.ps1` 用，默认 `D:\dsh`） |
| `DSH_PET_CHROME` | Chrome 可执行文件路径（`浏览器.mjs` 用） |
