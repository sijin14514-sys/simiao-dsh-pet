# 02 · 即梦图生视频自动化

目标：把"上传首帧 → 粘提示词 → 点生成 → 等出片 → 取回 mp4"做成可重复执行的脚本，而不是手点 20 次。
本文记录**能跑通的形态**和**必须绕开的坑**（每一步都实际翻过车）。

## 方案：Playwright 驱动本机 Chrome + 本地控制口

不用 API（图生视频的网页额度往往比 API 便宜甚至免费），而是驱动你自己已登录的浏览器：

1. **`tools/浏览器.mjs`**：用 `playwright-core` 起一个**专用配置目录**的 Chrome（登录一次长期复用），
   同时开一个本地控制口 `http://127.0.0.1:7799/cmd`，支持
   `goto / eval / screenshot / click / typeInto / dropFile / saveUrl / wheel ...`。
   把"浏览器操作"变成一条条 HTTP 指令，便于逐步调试。
   - 需要 `node tools/浏览器.mjs` **常驻**在另一个窗口，并且先在里面登录一次即梦。
   - 用 `process.env.DSH_PET_CHROME` 指定 Chrome 路径，默认取 Windows 常见安装位置。
2. **`tools/即梦-26-批量生成v2.mjs`**：批量循环。每个动作：开页面 → 挂首帧 → 写提示词 → 提交 →
   等侧边栏出现新任务 → 点开它 → 取回视频 → **四道质检**。
3. **`tools/即梦-40/41`**：结果收集与下载。适合"人工先跑一批，再统一取回"的工作方式。

## 必须绕开的坑

### 1) 上传首帧：合成点击无效，必须真拖放

即梦的参考图入口**不响应 `element.click()` / `page.click()`**，也就不会触发文件选择器。
可行做法是在页面里伪造一次拖放：

```js
const file = new File([bytes], name, { type: 'image/png' });
const dt = new DataTransfer(); dt.items.add(file);
for (const type of ['dragenter', 'dragover', 'drop'])
  el.dispatchEvent(new DragEvent(type, { bubbles: true, cancelable: true, dataTransfer: dt }));
```

### 2) 首帧"看起来挂上了"不等于挂上了 —— 必须校验

最开始我用"页面上有几张 blob 图"判断，结果**被头像和旧缩略图骗过**：首帧其实没挂上，
模型就自由发挥，生成出一只**完全不同的角色**（黑发猫娘）。

正确判据：**存在 `src` 以 `blob:` 开头、`naturalWidth ≥ 600` 的 `<img>`**（那就是刚上传的首帧缩略图）。
不满足就重试拖放，三次仍失败就跳过这个动作——宁可不做，也别生成一个别的角色。

### 3) 结果 CDN 直连 403

生成结果的 mp4 在 CDN 上，直接 `fetch` 会 403。要用**浏览器上下文**（带 cookie 和 Referer）：

```js
await context.request.get(url, { headers: { referer: 'https://jimeng.jianying.com/' } });
```

### 4) 结果面板是会话级的，且页面里混着示例视频

- 刷新页面后结果面板就空了，历史要回**左侧"对话"列表**里点开。
- 页面同时存在**官方示例视频**和**上一次的结果**，用"页面上第 N 个 video"判断必然抓错
  （我们曾把同一段视频当成两个动作下载了两次，靠 SHA256 查重才发现）。
- 可靠做法：**提交后等侧边栏出现新任务**，再点开那个任务取它的视频。

### 5) 对话历史是虚拟滚动的

一个"对话"里堆了很多次生成时，DOM 只渲染可视区。要**逐步滚动**（每次 400px、停 2 秒）才能全部捞出，
并按"提示词文本 ↔ 视频元素"的**文档坐标就近配对**——注意滚动的是内层容器（`div[class*=viewport]`），
不是 `window`。

### 6) 任务名是平台自动起的，不能用来判断动作

平台会把任务命名成"猫耳女仆晃钱袋绿幕动画"这种**看上去相关、实际对不上**的名字。
判断某个结果属于哪个动作，只能**按提示词正文匹配**（我们生成提示词时用的是同一份模板，正文可精确比对）。

## 成本意识

- 视频按条计费（本文环境约 30~45 积分/5 秒），**首条常有"限免"**，额度耗尽后无法继续。
- 页面会显示"本次消耗 / 原价"，提交前先看一眼；批量循环里要**先读额度再决定是否继续**。
- 生成是抽卡：**同一个提示词要多抽几张挑**，构图/角色跑偏的直接弃掉重来（别硬着头皮入库）。
