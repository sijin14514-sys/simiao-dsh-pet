# 04 · 桌宠配置与节奏设计

pet pack 的配置就是"这个种类有哪些动画、权重多少、实例长什么样"。本文给出可直接套用的模板与调参经验。

## 一、最小可用配置

放在 `$DSH_HOME/dsh-pet/pet/<前缀>-config.json`，配对目录 `$DSH_HOME/dsh-pet/pet/<前缀>-animation/`。

```jsonc
{
  "pets": [
    {
      "id": "simiao",                 // 实例 id（可多只，共享同一套动画池）
      "name": "肆喵",                 // 显示名
      "size": 380,                    // 显示宽度（px）
      "balanceEnabled": true,         // 是否显示余额气泡
      "display": "web",               // web | desktop | both | none
      "position": { "corner": "bottom-right", "marginX": 24, "marginY": 24 }
    }
  ],
  "animations": {
    "idle": ["待机呼吸"],                                            // 必填（可为空数组，但别为空）
    "turn": [],                                                     // 转身类（播完会翻转朝向）
    "drag": ["被鼠标拖拽悬空反抗"],                                    // 拖拽中播放
    "clicks": ["点击回应-开心跃动", "被吓一跳", "生气跺脚", "鼓掌庆祝", "鞠躬"],  // 点击时随机抽 1
    "moves": { "default": { "minDist": 60, "maxDist": 240, "margin": 20, "leadSec": 2, "tailSec": 2 }, "actions": [{ "name": "小碎步走路" }] },
    "categories": [
      { "id": "小动作", "weight": 12, "actions": ["左右张望", "招手打招呼", "摇头晃脑", "冒爱心", "原地转圈"] },
      { "id": "待机小动作", "weight": 10, "actions": ["打瞌睡", "抱着枕头睡觉", "看书", "擦汗", "戴耳机听歌"] },
      { "id": "吃喝", "weight": 8, "actions": ["吃零食"] }
    ],
    "events": { "balance": ["余额-钱袋如常"] }                        // 余额档位：数组顺序=档位顺序，必须非空
  },
  "animationWeights": { "idle": 65, "turn": 0, "move": 5 },           // 顶层权重
  "eventsRefreshSec": { "balance": 1800 }                            // 事件刷新周期（全局属性，pet 文件里写了也不生效）
}
```

## 二、权重怎么读

插件每段动画播完，按权重掷骰决定下一个：

- `idle` / `turn` / `move` 三个顶层权重 + 所有分类权重**合计 100**；
- 落在分类里 → 该分类内**随机抽一个动作**；
- `clicks` / `drag` / `events` 不进随机链，只由交互或事件触发；`clicks` 是"每次点击随机抽 1"，所以
  **多放几段就是"点击反应多样化"**。

以上面这份配置为例：**65% 时间在站立呼吸**，12% 环顾四周/挥手之类的主动小动作，
10% 打瞌睡/看书这类安静的，8% 吃零食，5% 走路。

## 三、让节奏"不显得忙"的三个做法

1. **`idle` 池只放"站着不动"的那一段**（呼吸）。这是最简单有效的一招：如果 idle 池里放了 6 段各不相同的动作，
   她就会像一直在表演。
2. **把"安静的小动作"另开一个权重低的分类**（如上面的 `待机小动作` 10%），而不是塞进 idle 池。
3. 想更安静就调高 `animationWeights.idle`（65 → 80），分类权重相应减少，合计保持 100。

## 四、其它经验

- **同一动画名会出现在多个池里**？合法，但同一段被反复抽到会显得单调，池子尽量多样化。
- **动作片段越短越"活"**：3~5 秒一段比 10 秒一段更不容易看出循环。
- **多实例**：`pets` 数组里加多项即可（各自独立 size / 位置），共享同一套动画池与素材。
- **排错**：配置非法、缺 `-animation/` 目录、实例 id 冲突 → 插件会**显式报错并跳过该宠物**，
  不会静默兜底；浏览器控制台 / DSH 日志里能看到原因。
- **文件宠物不出现在设置页**（dsh-pet 的既定行为）：改大小/位置直接编辑 json，刷新页面生效。
